เข้าสู่ระบบ

เข้าสู่ระบบด้วยบัญชีนิสิตเพื่อส่งผลงาน (ระบบสาธิต — ดูรายชื่อ/รหัสผ่านตัวอย่างได้ที่ README ของ prototype-v2)

เข้าสู่ระบบไม่สำเร็จ ตรวจสอบอีเมล/รหัสผ่านอีกครั้ง

เผยแพร่ผลงานสนับสนุนชุมชน

บัญชีนี้ไม่มีสิทธิ์ส่งผลงาน — เฉพาะบทบาท นิสิต เท่านั้นที่ส่งผลงานได้ (ดู ACL.md § อาจารย์: ทำไม่ได้ — ส่งผลงานแทนนิสิต)

เผยแพร่ผลงานสนับสนุนชุมชน

ผลงานของคุณจะถูกส่งให้อาจารย์ (ผู้ดูแลระบบ) ตรวจสอบและอนุมัติก่อน จึงจะเผยแพร่ได้

ลากไฟล์มาวาง หรือ
กรุณาระบุชื่อผลงานก่อนเผยแพร่
DRAFT — วิธีเชื่อมโยงผลงานกับพื้นที่ของชุมชนยังเป็น Open Question (ตัวอย่างนี้สมมติให้เลือกจาก dropdown)
ℹ️ ผลงานนี้จะยังไม่เผยแพร่ให้บุคคลอื่นเห็น จนกว่าอาจารย์จะกดอนุมัติ — เวอร์ชันนี้บันทึกลง Firestore จริง (project `lsh-nammon`, collection `LSHRequests`) ตัวตนผู้ส่งมาจากบัญชีที่ login อยู่โดยตรง
บันทึกไม่สำเร็จ ลองใหม่อีกครั้ง
