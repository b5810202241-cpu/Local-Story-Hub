เข้าสู่ระบบ

เข้าสู่ระบบด้วยบัญชีนิสิตเพื่อส่งผลงาน (ระบบสาธิต — ดูรายชื่อ/รหัสผ่านตัวอย่างได้ที่ README ของ prototype-v2)

เข้าสู่ระบบไม่สำเร็จ ตรวจสอบอีเมล/รหัสผ่านอีกครั้ง
ยังไม่มีบัญชี?

สมัครสมาชิก (นิสิต)

บัญชีที่สมัครใหม่ต้องรอการอนุมัติจากอาจารย์ที่ปรึกษาก่อน จึงจะเข้าใช้งานได้

สมัครไม่สำเร็จ ตรวจสอบข้อมูลอีกครั้ง
มีบัญชีอยู่แล้ว?

บัญชีของคุณกำลังรอการอนุมัติ

สมัครสมาชิกสำเร็จแล้ว แต่ต้องรอให้อาจารย์ที่ปรึกษาอนุมัติก่อน จึงจะส่งผลงานได้ — ลองเข้าสู่ระบบใหม่ภายหลัง

บัญชีนี้ไม่ได้รับการอนุมัติ

อาจารย์ที่ปรึกษาไม่อนุมัติบัญชีนี้

บัญชีนี้ใช้งานต่อไม่ได้ — หากต้องการเข้าใช้งานต้องสมัครสมาชิกใหม่เท่านั้น

เผยแพร่ผลงานสนับสนุนชุมชน

บัญชีนี้ไม่มีสิทธิ์ส่งผลงาน — เฉพาะบทบาท นิสิต เท่านั้นที่ส่งผลงานได้ (ดู ACL.md § อาจารย์: ทำไม่ได้ — ส่งผลงานแทนนิสิต)

เผยแพร่ผลงานสนับสนุนชุมชน

ผลงานของคุณจะถูกส่งให้อาจารย์ (ผู้ดูแลระบบ) ตรวจสอบและอนุมัติก่อน จึงจะเผยแพร่ได้

ยังไม่เคยส่งผลงานเลย
ลากไฟล์มาวาง หรือ
กรุณาระบุชื่อผลงานก่อนเผยแพร่
ไม่พบชุมชนที่อนุมัติแล้วในระบบขณะนี้
รายชื่อชุมชนดึงจากบัญชีชุมชนจริงที่อาจารย์อนุมัติแล้วเท่านั้น (collection users, role: 'community') — ถ้าชุมชนที่ต้องการยังไม่ขึ้นในลิสต์ แปลว่ายังไม่ได้สมัครบัญชีหรือยังไม่ผ่านการอนุมัติ
AI backend (Cloudflare Worker) ยังไม่ได้ deploy หรือยังไม่ได้ตั้งค่า URL จริงใน ai-assist-config.js (ดู cf-worker/README.md)
🤖 ข้อเสนอจาก AI — โปรดตรวจสอบก่อนยืนยัน

แตะ/คลิกบนแผนที่เพื่อปักหมุดตำแหน่งจริงของสถานที่ในผลงานนี้ (FR-2.3) — ไม่บังคับ ข้ามได้ถ้าไม่ทราบพิกัด

ℹ️ ผลงานนี้จะยังไม่เผยแพร่ให้บุคคลอื่นเห็น จนกว่าอาจารย์จะกดอนุมัติ — เวอร์ชันนี้บันทึกลง Firestore จริง (project `lsh-nammon`, collection `LSHRequests`) ตัวตนผู้ส่งมาจากบัญชีที่ login อยู่โดยตรง
