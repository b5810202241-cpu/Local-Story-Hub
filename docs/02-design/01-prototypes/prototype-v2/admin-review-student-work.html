ตรวจสอบผลงานนิสิตที่รออนุมัติ

ผลงานที่นิสิตส่งเข้ามาจะเผยแพร่ได้ก็ต่อเมื่อได้รับอนุมัติจากอาจารย์ที่นี่เท่านั้น

DRAFT — เวอร์ชันนี้อ่าน/เขียนข้อมูลจาก Firestore จริง (project `lsh-nammon`, collection `LSHRequests`) แบบ real-time ผ่านบัญชี Firebase Authentication จริง — ปุ่มอนุมัติ/ไม่อนุมัติแสดงเฉพาะเมื่อ login ด้วยบทบาทอาจารย์เท่านั้น

บัญชีผู้ใช้ใหม่ที่รออนุมัติ (นิสิต + ชุมชน)

DRAFT — เวอร์ชันนี้จำลองการแจ้งเตือน (ยังไม่ได้ส่งอีเมลจริงถึงอาจารย์) ด้วยแบนเนอร์ด้านบนแทน
ยังไม่มีบัญชีผู้ใช้ใหม่รอการอนุมัติในขณะนี้

คำขอแก้ไขข้อมูลชุมชนที่รอพิจารณา

ยังไม่มีคำขอแก้ไขข้อมูลชุมชนรอพิจารณาในขณะนี้

AI สรุปภาพรวมผลงานที่รอพิจารณา

อ่านผลงานที่รอพิจารณาทั้งหมด สรุปภาพรวมให้อ่านง่ายก่อนตรวจทีละชิ้น แล้วบันทึกสรุปนี้ลง Firestore (collection AiSummaries) พร้อมจด log การทำงานไว้

AI backend (Cloudflare Worker) ยังไม่ได้ deploy หรือยังไม่ได้ตั้งค่า URL จริงใน ai-assist-config.js (ดู cf-worker/README.md)
🤖 สรุปโดย AI — โปรดตรวจสอบก่อนใช้งาน (บันทึกลง Firestore แล้ว)
