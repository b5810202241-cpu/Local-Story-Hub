# Test Plan — สอดคล้องกับ User Journey

สร้าง test case จาก User Journey ทั้ง 3 persona ใน [[../../02-design/01-prototypes/index|02-design/01-prototypes]] โดยแปลง Acceptance Criteria ของ backlog item ที่แต่ละ journey step อ้างอิงให้เป็น test case โดยตรง (ไม่ได้แต่ง test case ใหม่ที่ไม่มีอ้างอิงใน Acceptance Criteria เดิม)

> **ขอบเขต**: ครอบคลุมเฉพาะ backlog item ที่ปรากฏเป็น step ใน User Journey ทั้ง 3 ไฟล์ — BL-014 (เก็บ log 90 วัน) และ BL-017 (บันทึกหลักฐาน consent) เป็นพฤติกรรม backend ที่ไม่มี step ใน journee ใดโดยตรง จึงยังไม่อยู่ใน test plan ฉบับนี้
>
> **สถานะรวม**: ทุก test case เป็น **ยังไม่ทดสอบ** เพราะยังไม่มีซอร์สโค้ดให้ทดสอบจริง (ดู `CLAUDE.md`) — เอกสารนี้เตรียมไว้ล่วงหน้าเพื่อให้พร้อมทดสอบทันทีที่มีระบบจริง — test case ที่มาจาก journey step ที่ยังเป็น DRAFT (ขึ้นกับ Open Question) ถูกทำเครื่องหมายไว้ในคอลัมน์หมายเหตุ ต้องยืนยัน requirement ให้นิ่งก่อนถือเป็น test case สุดท้าย
