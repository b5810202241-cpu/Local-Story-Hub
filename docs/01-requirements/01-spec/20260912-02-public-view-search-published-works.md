# ดูผลงานนิสิตที่เผยแพร่แล้วโดยไม่ต้อง Login

- **วันที่บันทึก:** 2026-09-12
- **สถานะ:** Draft

## Context

ผู้ใช้ถามว่าควรมีหน้าให้บุคคลทั่วไปดูผลงานนิสิตที่เผยแพร่แล้วโดยไม่ต้อง login หรือไม่ — แนะนำว่าควรมี เพราะสอดคล้องกับ Decision Log เดิมใน [[../../02-design/02-technical/architecture|02-technical/architecture]] (2026-08-28) ที่ระบุว่านักท่องเที่ยวต้องมีบัญชีเฉพาะตอนเขียนรีวิว/บันทึกสถานที่โปรด ไม่ใช่ตอนดู/อ่านเนื้อหา และ API Spec เชิงแนวคิดมี operation "ดูผลงานนิสิตที่เกี่ยวข้องกับชุมชน (เฉพาะ published)" ระบุไว้แล้วแต่ยังไม่เคย implement จริง — ผู้ใช้ยืนยันให้ทำ พร้อมระบุขอบเขตชัดเจน

## ต้นฉบับ (Verbatim จากผู้ใช้)

> ทำให้สามารถดูผลงานนิสิตได้โดยไม่ต้องล็อคอิน แต่จะไม่สามารถทำอย่างอื่นได้อีกนอกจากดูผลงาน ยกเว้นการเสิร์ชค้นหาสถานที่ที่สนใจ

## ขอบเขต (Scope)

- **In scope:** ผู้เยี่ยมชมที่ไม่ได้ login เห็นเฉพาะผลงานที่สถานะ "อนุมัติ" (เผยแพร่แล้ว) เท่านั้น; ค้นหา/กรองผลงานตามสถานที่/ชุมชนที่สนใจได้
- **Out of scope:** การกระทำอื่นทั้งหมดที่ต้อง login เหมือนเดิม (ส่งผลงาน, อนุมัติ/ไม่อนุมัติ, สมัครบัญชี, รีวิว, บันทึกสถานที่โปรด ฯลฯ) — ผู้เยี่ยมชมที่ไม่ login ทำได้แค่ดู+ค้นหาเท่านั้น ไม่มีสิทธิ์อื่นใดเพิ่มเติม

## Functional Requirements

1. บุคคลทั่วไป (ไม่ต้อง login) ดูรายการผลงานนิสิตที่มีสถานะ "อนุมัติ" ได้
2. บุคคลทั่วไปค้นหา/กรองผลงานตามสถานที่/ชุมชนที่สนใจได้ (เช่น ชุมชนบ้านผาบ่อง, ชุมชนริมน้ำแม่กลอง, ชุมชนดอยสูง)
3. ผลงานที่สถานะ "รอพิจารณา" หรือ "ไม่อนุมัติ" ต้องไม่แสดง/เข้าถึงได้จากบุคคลทั่วไปเลย ไม่ว่ากรณีใด
4. การกระทำอื่นนอกเหนือจากดู/ค้นหา (ส่งผลงาน, อนุมัติ/ไม่อนุมัติ, สมัครบัญชี ฯลฯ) ยังคงต้อง login เหมือนเดิม ไม่มีการเปลี่ยนแปลงสิทธิ์เดิม

## Business Rules

- **เฉพาะผลงานสถานะ "อนุมัติ" เท่านั้นที่เปิดให้บุคคลทั่วไปเห็นได้โดยไม่ login** — ผลงานสถานะอื่นต้องถูกซ่อนจากการเข้าถึงแบบไม่ login เสมอ ไม่มีข้อยกเว้น (ต้องบังคับที่ระดับ backend/security rules ไม่ใช่แค่ซ่อนที่ UI)
- **ผู้เยี่ยมชมที่ไม่ login ทำได้แค่ดูและค้นหาเท่านั้น** ไม่มีสิทธิ์ทำการกระทำอื่นใดในระบบ
- **ขอบเขตของ "ค้นหาสถานที่ที่สนใจ" คือค้นหาเฉพาะตามชื่อชุมชนเท่านั้น** (field `community` ที่มีอยู่แล้วใน `LSHRequests`) ไม่รวมการค้นหาจากชื่อผลงาน/คำในเนื้อหา (ตัดสินใจ 2026-09-22 — ปิด Open Question เดิม, ตรงกับที่ implement จริงแล้วใน `published-works.html`)
- **หน้าที่แสดงผลเป็นหน้าใหม่แยกต่างหาก** (`published-works.html`) ไม่รวมเข้ากับหน้าฝั่งนักท่องเที่ยวใน prototype-v1 (`tourist-search-results.html`) (ตัดสินใจ 2026-09-22 — ปิด Open Question เดิม, ตรงกับที่ implement จริงแล้ว)
