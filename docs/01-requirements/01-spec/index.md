# 01 - Spec

เก็บเอกสาร **ข้อกำหนดของโปรเจกต์ (Requirements / Specification)** เช่น

- Feature requirements — ฟีเจอร์ที่ต้องมีในระบบ
- User stories / use cases
- Business rules และเงื่อนไขทางธุรกิจ
- ขอบเขตของโปรเจกต์ (scope) — สิ่งที่ทำ และสิ่งที่ไม่ทำ

เอกสารในโฟลเดอร์นี้ควรเป็น **ต้นทาง (source of truth)** ของความต้องการ ก่อนที่จะถูกแตกไปเป็นแผนงานใน [[../02-plan/index|02-plan]] และงานย่อยใน [[../03-task/index|03-task]]

## เอกสารในหมวดนี้

- [[local-story-hub|Local Story Hub — Product Spec]] — สเปคของโปรเจกต์ Local Story Hub สรุปจากไฟล์ requirement ที่ผู้ใช้แนบมา
- [[20260822-01-it-log-pdpa-consent|IT Log Retention (90 วัน) และ PDPA Consent]] — ครอบคลุมผู้ใช้งานทุกกลุ่ม ไม่ใช่กลุ่มเป้าหมายกลุ่มใดกลุ่มหนึ่ง
- [[20260912-01-account-registration-approval|การอนุมัติบัญชีผู้ใช้ใหม่โดยอาจารย์ที่ปรึกษา]] — บัญชีที่สมัครใหม่ต้องรออนุมัติจากอาจารย์ที่ปรึกษาก่อนจึง login เข้าใช้งานได้
- [[20260912-02-public-view-search-published-works|ดูผลงานนิสิตที่เผยแพร่แล้วโดยไม่ต้อง Login]] — บุคคลทั่วไปดู/ค้นหาผลงานที่อนุมัติแล้วได้โดยไม่ต้อง login แต่ทำอย่างอื่นไม่ได้
